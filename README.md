# CampusSolve – Library Record Application

## Introduction
CampusSolve is a Python-based Library Record Application designed to simplify library management.

## Objectives
- Maintain book records.
- Register library members.
- Manage book issuing and returning.
- Search library records.
- Generate summary reports.

## Technologies Used
- Python 3
- JSON
- CSV
- VS Code

## Python Modules
- json
- csv
- os
- datetime
- collections

## Main Features
1. Add Books
2. View Books
3. Register Members
4. View Members
5. Issue Books
6. Return Books
7. View Transactions
8. Search Records
9. Generate Summary
10. Export Reports
11. Bulk Data Import
12. Sample Data

## Execution
Run the following command:

python campus_solve.py

## Data Storage
JSON is used to store library records, while CSV is used for importing and exporting data.

## Conclusion
CampusSolve provides a simple and efficient solution for managing library records using Python.
